# NodeRose
Rosebud source code to NodeJS Server for MMO conceptor.

Copy this NodeRose project into your project RosebudAI source code.
Open terminal next with NodeJS install in your computer write "npm install" and "node nodejs.js" at the folder of your project.
Go to http://localhost:4321
Enjoy your game.

If Rosebud want to take this for the must, NodeRose source code is welcome for the conception of MMO starter code.

NodeRose technical is make with OlapCube and WebSocket.
